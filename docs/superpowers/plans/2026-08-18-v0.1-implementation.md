# LanTally v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Expand later milestones into bite-sized TDD steps at the start of that milestone; do not implement M2+ until M1 tests pass.

**Goal:** Ship a privacy-first, read-only, self-hosted traffic ledger that accepts reports from multiple nodes, accounts per-device direct and proxied usage, applies disclosed proxy multipliers, and presents daily and monthly history in an embedded UI.

**Architecture:** Statically compiled Go agents discover collectors, convert counters into monotonic interval deltas, and push gzip JSON batches. `lantally-server` enrolls nodes, deduplicates on `node_id + boot_id + sequence`, resolves device identity, writes SQLite metadata and VictoriaMetrics series, and serves an embedded React UI. The default image runs the server and VictoriaMetrics behind one port and one volume.

**Tech Stack:** Go 1.26 (`go1.26.6` at plan time), stdlib `net/http` ServeMux, `modernc.org/sqlite`, `golang.org/x/crypto/argon2`, VictoriaMetrics v1.150.0, React 19 + TypeScript + Vite.

## Global Constraints

- Module path is `github.com/misakayyds/lantally`. Renaming later changes only `go.mod` and imports, never the wire protocol.
- Ingest protocol is versioned JSON + gzip over HTTP POST. No gRPC or protobuf in v0.1. Schema lives in `proto/v1/`.
- v0.1 must not implement remote command execution, traffic blocking, rate limiting, routing changes, firewall changes, or proxy-policy writes.
- Never commit subscription URLs, API secrets, node tokens, IP inventories, browsing destinations, packet captures, or real household traffic fixtures.
- Tests use synthetic addresses from `203.0.113.0/24` (TEST-NET-3) and locally administered MACs `02:00:00:00:00:xx`.
- Domain and destination collection is opt-in and disabled by default. Metric labels are a closed whitelist.
- OpenWrt buffers are memory-only and bounded by default. Unsent batches lost on reboot are reported as gaps, never estimated.
- Default deployment is one container, one persistent volume at `/var/lib/lantally`, one public HTTP port `8080`. VictoriaMetrics binds `127.0.0.1:8428` only.
- Agents are outbound-only and do not listen on a management port.
- Server credentials are stored as argon2id hashes. Node tokens are unique, revocable, and shown in plaintext only once.
- Do not add nlbwmon bytes to Mihomo bytes. `total` prefers nlbwmon, else iface, else Mihomo. `direct` and `proxy` come only from a proxy adapter.
- Unknown multipliers stay `proxy_unadjusted` and are marked in the UI. Never guess a multiplier.
- Agents do not auto-update in v0.1.
- Public docs and this repository must not contain private LAN addresses or real topology.

## Protocol and types

`POST /v1/ingest`

- `Authorization: Bearer <node-token>`
- `Content-Encoding: gzip`
- `Content-Type: application/json`

Unknown JSON fields that would drop counters must be rejected. `protocol_version` must equal `1`.

```go
package protocol

type Capability string

const (
	CapIface     Capability = "iface"
	CapConntrack Capability = "conntrack"
	CapNlbwmon   Capability = "nlbwmon"
	CapMihomo    Capability = "mihomo"
)

type GapReason string

const (
	GapReboot          GapReason = "reboot"
	GapBufferDrop      GapReason = "buffer_drop"
	GapCollectorReset  GapReason = "collector_reset"
)

type Batch struct {
	ProtocolVersion int           `json:"protocol_version"`
	SiteID          string        `json:"site_id"`
	NodeID          string        `json:"node_id"`
	BootID          string        `json:"boot_id"`
	Sequence        uint64        `json:"sequence"`
	SampledAt       time.Time     `json:"sampled_at"`
	IntervalMS      int           `json:"interval_ms"`
	Capabilities    []Capability  `json:"capabilities"`
	Interfaces      []IfaceDelta  `json:"interfaces"`
	Devices         []DeviceDelta `json:"devices"`
	Proxy           *ProxyDelta   `json:"proxy,omitempty"`
	Gaps            []Gap         `json:"gaps,omitempty"`
}

type IfaceDelta struct {
	Name    string `json:"name"`
	RxDelta uint64 `json:"rx_delta"`
	TxDelta uint64 `json:"tx_delta"`
}

type DeviceSource string

const (
	SourceNlbwmon DeviceSource = "nlbwmon"
	SourceMihomo  DeviceSource = "mihomo"
	SourceNeigh   DeviceSource = "neigh"
)

type DeviceDelta struct {
	ObsIP   string       `json:"obs_ip"`
	ObsMAC  string       `json:"obs_mac,omitempty"`
	RxDelta uint64       `json:"rx_delta"`
	TxDelta uint64       `json:"tx_delta"`
	Source  DeviceSource `json:"source"`
}

type ProxyDelta struct {
	ByOutbound []OutboundDelta `json:"by_outbound"`
}

type OutboundDelta struct {
	Name       string `json:"name"`
	DirectRx   uint64 `json:"direct_rx"`
	DirectTx   uint64 `json:"direct_tx"`
	ProxyRx    uint64 `json:"proxy_rx"`
	ProxyTx    uint64 `json:"proxy_tx"`
	Unadjusted bool   `json:"unadjusted"`
}

type Gap struct {
	Reason GapReason `json:"reason"`
	From   time.Time `json:"from"`
	To     time.Time `json:"to"`
}
```

Idempotency key: `(node_id, boot_id, sequence)`. Duplicate POSTs acknowledge the stored batch and must not change totals. A new `boot_id` is a reset boundary, never a negative delta.

Metric names:

- `lantally_bytes_total` (counter)
- `lantally_rate_bps` (gauge)
- `lantally_node_last_report_timestamp_seconds` (gauge)

Allowed labels only: `site_id`, `node_id`, `device_id`, `class`, `direction`.

`class` values: `total` | `direct` | `proxy_raw` | `proxy_adjusted` | `proxy_unadjusted`.

`direction` values: `rx` | `tx`.

Public HTTP (no control plane):

- `POST /v1/ingest`
- `POST /v1/enroll` (admin session; token plaintext returned once)
- `DELETE /v1/nodes/{id}/credentials`
- `GET /v1/overview`
- `GET /v1/devices`
- `GET /v1/nodes`
- `GET /v1/proxy`
- `GET /v1/alerts`
- `POST /v1/provider-checkpoints`
- `GET /healthz`
- `GET /metrics` (process metrics only)
- static UI `/`

Handlers must not call nftables, iptables, UCI, Mihomo config writes, or a shell. Tests must assert those routes and packages do not exist.

## Testing strategy

- Unit: deltas, resets, dedup, multipliers, identity evidence, label whitelist, redaction.
- Property: counters never decrease; duplicate or reordered batches do not inflate totals.
- Integration: simulated agents, retries, server restart, storage outage, protocol-version rejection.
- Fixtures: synthetic nlbwmon and Mihomo only.
- End-to-end: all-in-one start, enroll, ingest, device view, backup, restore.
- Control-plane guard: no routes or packages that write routing, firewall, or proxy config.
- CI fixture scan: fail on subscription URL patterns, bearer tokens, and RFC1918 addresses inside `testdata/` and `proto/`.

Resource targets remain:

- Agent RSS at most 25 MB on supported gateways (measure on real hardware in M9; keep a comment and optional benchmark in M3).
- Idle CPU near zero; average collection CPU below 1% under representative home traffic.
- Default all-in-one memory target at most 512 MB for a small install (observe under compose limits; do not OOM-kill in CI).
